# To-Do List Application 📝

## 📌 Project Overview
This is a **simple Flask-based To-Do List web application** that allows users to add and delete tasks.  
It is designed for beginners to understand **CRUD operations**, **Flask routing**, and **basic web development**.

## 🚀 Features
- Add new tasks  
- Delete existing tasks  
- Clean and simple UI  
- Flask backend with HTML templates  
- Beginner-friendly project structure  

## 🛠️ Tech Stack
- **Backend:** Python (Flask)  
- **Frontend:** HTML, CSS  
- **Template Engine:** Jinja2  

## 📂 Project Structure
```
To-Do-List-Application/
│
├── static/          # CSS files
├── templates/       # HTML templates
├── app.py           # Main Flask application
└── README.md        # Project documentation
```

## ▶️ How to Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/Monicram/To-Do-List-Application.git
   ```

2. Navigate to the project folder:
   ```bash
   cd To-Do-List-Application
   ```

3. Install Flask:
   ```bash
   pip install flask
   ```

4. Run the application:
   ```bash
   python app.py
   ```

5. Open your browser and go to:
   ```
   http://127.0.0.1:5000/
   ```
